# Project 3 - Rock-Paper-Scissors Game

This is a Django-based web application for Rock-Paper-Scissors game where the user plays against the computer.


## Features:

1. Web-based GUI interface using Django.  
2. User can selects Rock, Paper Scissors by click on display.   
3. Computer makes a random choice.  
4. The app determines and displays the result (win, lost or tie).  
5. Option to start new game.


## Requirements:
  - Python 3.x
  - Django


## Usage:
  - Select Rock, Paper or Scissors on the webpage.
  - View the result showing whether you won, lost or tied.
  - Option to play another round.


## Note:-
  - Make sure you have Python and Django installed.
